# Decisions

One dated line per decision the user makes.

- 2026-10-13: Game is "golden-hour explore": third-person walk, five hidden lanterns, ends on a vista. No combat, no inventory, UI is only a lantern counter and a start screen.
- 2026-10-13: Look is Firewatch-style; lighting first. Props from Meshy or CC0 packs, matched to one style frame.
- 2026-10-13: Character is a free CC0 animated character (Quaternius or KayKit), not AI-generated.
- 2026-10-13: Stack is three.js (latest stable, pinned) + Vite, deployed to GitHub Pages on every push to main.
- 2026-10-13: Must play on laptop (keyboard + mouse) and phone (touch joystick, drag to look), with a tap-to-start screen.
- 2026-10-13: Style frame 1 (close to Firewatch) is the look target for Day 2 and all props.
- 2026-10-16: Add Shift to sprint and Space to jump (with a phone jump button) to the controls item (1D).
- 2026-10-16: Valley wall should be low enough to see the mountains beyond it; paths must be clearly visible.
- 2026-10-16: Shift sprint is 3x walking speed for fast playtesting; walking speed stays as is. Rocks block the player.
