# Practice Glade

**Play: https://crabtoast90-dev.github.io/practice-glade/** (add `?debug` for an FPS readout)

A small golden-hour exploration game: walk a stylized valley, find five hidden lanterns, end on a vista.
Throwaway practice project for testing a build workflow. See CLAUDE.md and PLAN.md.

Run locally: `npm install`, then `npm run dev`. Self-check: `npm run check`.
